## CS_02_02. Сумма двух чисел

### Задание
| CS_02_02 ||
| ------ | ------- |
| **Темы:** | `Split`, `int.Parse`, арифметика |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два целых числа и выведи их сумму:

~~~text
Sum: <сумма>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2 3` | `Sum: 5` |
| `-4 4` | `Sum: 0` |
