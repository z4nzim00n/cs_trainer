## CS_02_03. Строка целиком

### Задание
| CS_02_03 ||
| ------ | ------- |
| **Темы:** | `Console.ReadLine`, пробелы в строке |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка текста |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку целиком, включая пробелы, и выведи:

~~~text
Line: <строка>
~~~

Например, для `hello world` вывод `Line: hello world`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello world` | `Line: hello world` |
| `a  b` | `Line: a  b` |
