## CS_02_05. Смешанный ввод

### Задание
| CS_02_05 ||
| ------ | ------- |
| **Темы:** | `Split`, `int.Parse`, `string`, несколько значений |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Возраст и имя через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


В одной строке заданы целое число и имя. Выведи:

~~~text
Age: <возраст>
Name: <имя>
~~~

Например, для `42 Bob`:

~~~text
Age: 42
Name: Bob
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `42 Bob` | `Age: 42`<br>`Name: Bob` |
| `7 Alice` | `Age: 7`<br>`Name: Alice` |
