## CS_02_04. Форматирование числа

### Задание
| CS_02_04 ||
| ------ | ------- |
| **Темы:** | `double`, `CultureInfo.InvariantCulture`, формат `F2` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одно дробное число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай дробное число и выведи его с двумя знаками после точки:

~~~text
Value: 3.14
~~~

Разделитель — точка, независимо от региональных настроек.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3.14159` | `Value: 3.14` |
| `2` | `Value: 2.00` |

bash run_tests2_4.sh
