## CS_04_04. Разворот числа

### Задание
| CS_04_04 ||
| ------ | ------- |
| **Темы:** | `long`, `while`, `% 10`, переполнение |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Разверни число задом наперёд и выведи результат:

~~~text
1000000009 → 9000000001
~~~

Ведущие нули после разворота не печатаются: `120 → 21`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1234` | `4321` |
| `120` | `21` |
| `1000000009` | `9000000001` |

bash run_tests4_4.sh
