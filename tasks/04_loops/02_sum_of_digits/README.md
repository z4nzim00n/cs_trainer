## CS_04_02. Сумма цифр

### Задание
| CS_04_02 ||
| ------ | ------- |
| **Темы:** | `while`, `% 10`, `/ 10` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Неотрицательное целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди сумму цифр числа:

~~~text
12345 → 15
~~~

Выведи:

~~~text
Sum: 15
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `12345` | `Sum: 15` |
| `0` | `Sum: 0` |

```bash
bash run_tests4_2.sh
```
