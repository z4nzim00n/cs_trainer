## CS_04_01. Максимум последовательности

### Задание
| CS_04_01 ||
| ------ | ------- |
| **Темы:** | `for`, `int.MaxValue`, `int.MinValue` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди максимальное число в последовательности и выведи:

~~~text
Max: <число>
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 9 2 7 1` | `Max: 9` |
| `3`<br>`-5 -2 -8` | `Max: -2` |

bash run_tests4_1.sh
