## CS_04_06. Непарное число

### Задание
| CS_04_06 ||
| ------ | ------- |
| **Темы:** | XOR `^`, побитовые операции, циклы |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n` (нечётное), затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Каждое число встречается дважды, кроме одного. Найди это число.

~~~text
5
2 3 2 1 3
→ 1
~~~

Выведи:

~~~text
Unique: 1
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`2 3 2 1 3` | `Unique: 1` |
| `3`<br>`7 7 9` | `Unique: 9` |
