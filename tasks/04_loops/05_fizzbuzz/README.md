## CS_04_05. FizzBuzz

### Задание
| CS_04_05 ||
| ------ | ------- |
| **Темы:** | `for`, `if/else`, `%` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Целое число `n` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи числа от `1` до `n`, заменяя:

- кратные `3` — на `Fizz`;
- кратные `5` — на `Buzz`;
- кратные и `3`, и `5` — на `FizzBuzz`.

Каждое значение — на отдельной строке.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5` | `1`<br>`2`<br>`Fizz`<br>`4`<br>`Buzz` |
| `15` | `…`<br>`14`<br>`FizzBuzz` |

```bash
bash run_tests4_5.sh
```
