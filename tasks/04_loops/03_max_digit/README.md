## CS_04_03. Максимальная цифра

### Задание
| CS_04_03 ||
| ------ | ------- |
| **Темы:** | `while`, цифры числа, сравнение |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Неотрицательное целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди максимальную цифру числа и выведи:

~~~text
Max digit: 9
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `9073` | `Max digit: 9` |
| `0` | `Max digit: 0` |
