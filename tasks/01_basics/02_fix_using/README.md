## CS_01_02. Исправь using

### Задание
| CS_01_02 ||
| ------ | ------- |
| **Темы:** | `using System`, ошибки компиляции |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |


В файле `Program.cs` есть ошибка: пропущена строка `using System;`. Из-за
этого компилятор не знает имя `Console`.

Добавь нужный `using`, чтобы программа собралась и вывела:

~~~text
Fixed!
~~~
