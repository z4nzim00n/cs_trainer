## CS_01_01. Первая программа

### Задание
| CS_01_01 ||
| ------ | ------- |
| **Темы:** | `using System`, `class Program`, `static void Main`, `Console.WriteLine` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Напиши программу, которая выводит строку:

~~~text
Hello, C#!
~~~

Каждая программа на C# состоит из классов. Точка входа — статический метод
`Main`. Для консольного вывода используется `Console.WriteLine`.

~~~csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, C#!");
    }
}
~~~

`WriteLine` печатает значение и добавляет перевод строки.
