## CS_13_02. Сортировка лямбдой

### Задание
| CS_13_02 ||
| ------ | ------- |
| **Темы:** | `Comparison<T>`, лямбда, составной порядок |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` слов |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Отсортируй слова по длине, а при равной длине — по алфавиту:

~~~text
4
bbb a cc ab
→ a ab cc bbb
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4`<br>`bbb a cc ab` | `a ab cc bbb` |
| `3`<br>`bb aa c` | `c aa bb` |
