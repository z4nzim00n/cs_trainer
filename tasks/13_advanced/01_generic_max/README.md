## CS_13_01. Обобщённый максимум

### Задание
| CS_13_01 ||
| ------ | ------- |
| **Темы:** | дженерики, `IComparable<T>`, `where` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа, затем два слова |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши обобщённый метод `Max<T>` и примени его к числам и строкам:

~~~text
Max int: 7
Max string: banana
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 7`<br>`apple banana` | `Max int: 7`<br>`Max string: banana` |
