## CS_13_04. Перегрузка оператора

### Задание
| CS_13_04 ||
| ------ | ------- |
| **Темы:** | `operator +`, `static`, `ToString` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Четыре целых числа `x1 y1 x2 y2` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Vector` и перегрузи `+`, чтобы складывать векторы:

~~~text
1 2 3 4
→ (4, 6)
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1 2 3 4` | `(4, 6)` |
| `-1 5 1 -5` | `(0, 0)` |
