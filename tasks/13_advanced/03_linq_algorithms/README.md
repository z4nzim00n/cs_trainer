## CS_13_03. LINQ

### Задание
| CS_13_03 ||
| ------ | ------- |
| **Темы:** | `Where`, `Select`, `Sum`, LINQ |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди сумму квадратов чётных чисел:

~~~text
Sum: 56
~~~

Для `1 2 3 4 5 6` чётные — `2 4 6`, квадраты — `4 16 36`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `6`<br>`1 2 3 4 5 6` | `Sum: 56` |
| `3`<br>`1 3 5` | `Sum: 0` |
