## CS_06_03. Верхний и нижний регистр

### Задание
| CS_06_03 ||
| ------ | ------- |
| **Темы:** | `ToUpperInvariant`, `ToLowerInvariant` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи строку в верхнем и нижнем регистре:

~~~text
UPPER: HELLO
lower: hello
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `Hello World` | `UPPER: HELLO WORLD`<br>`lower: hello world` |
| `C#` | `UPPER: C#`<br>`lower: c#` |
