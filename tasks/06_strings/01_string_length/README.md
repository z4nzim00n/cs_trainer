## CS_06_01. Длина строки

### Задание
| CS_06_01 ||
| ------ | ------- |
| **Темы:** | `string.Length`, `Console.ReadLine` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Выведи длину строки:

~~~text
Length: 5
~~~

Пустая строка имеет длину `0`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello` | `Length: 5` |
| `C#` | `Length: 2` |
