## CS_06_04. Количество слов

### Задание
| CS_06_04 ||
| ------ | ------- |
| **Темы:** | `Split`, `StringSplitOptions.RemoveEmptyEntries` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка со словами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай количество слов, разделённых пробелами:

~~~text
Words: 3
~~~

Несколько пробелов подряд считаются одним разделителем.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `hello world foo` | `Words: 3` |
| `  one   two  ` | `Words: 2` |
