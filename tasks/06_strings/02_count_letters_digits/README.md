## CS_06_02. Буквы и цифры

### Задание
| CS_06_02 ||
| ------ | ------- |
| **Темы:** | `foreach` по строке, `char.IsLetter`, `char.IsDigit` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай в строке количество букв и цифр:

~~~text
Letters: 5
Digits: 2
~~~

Остальные символы (пробелы, знаки) не считаются.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `abc12` | `Letters: 3`<br>`Digits: 2` |
| `Hi, 2025!` | `Letters: 2`<br>`Digits: 4` |
