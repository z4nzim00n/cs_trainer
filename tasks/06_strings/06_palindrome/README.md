## CS_06_06. Палиндром

### Задание
| CS_06_06 ||
| ------ | ------- |
| **Темы:** | `char[]`, `Array.Reverse`, сравнение строк |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Проверь, читается ли строка одинаково в обе стороны:

~~~text
True
~~~

Выведи `True` или `False`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `level` | `True` |
| `hello` | `False` |
| `a` | `True` |
