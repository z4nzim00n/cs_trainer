## CS_03_01. Площадь круга

### Задание
| CS_03_01 ||
| ------ | ------- |
| **Темы:** | `double`, `Math.PI`, форматирование `F2` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Радиус круга |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай радиус и выведи площадь круга с двумя знаками после точки:

~~~text
Area: 12.57
~~~

Формула: `S = π · r²`. Используй `Math.PI`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2` | `Area: 12.57` |
| `1` | `Area: 3.14` |
