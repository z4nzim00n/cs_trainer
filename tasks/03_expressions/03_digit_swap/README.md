## CS_03_03. Обмен крайних цифр

### Задание
| CS_03_03 ||
| ------ | ------- |
| **Темы:** | `/`, `%`, разряды числа |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Четырёхзначное целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поменяй местами первую и последнюю цифры четырёхзначного числа.

~~~text
1234 → 4231
~~~

Выведи только результат.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1234` | `4231` |
| `1001` | `1001` |

bash run_tests3_3.sh
