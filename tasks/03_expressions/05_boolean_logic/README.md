## CS_03_05. Логическое выражение

### Задание
| CS_03_05 ||
| ------ | ------- |
| **Темы:** | `bool`, `&&`, `||`, сравнения |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Возраст и наличие билета (0 или 1) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Человек проходит на мероприятие, если ему `18` лет или больше **и** у него
есть билет. Билет обозначается `1`, его отсутствие — `0`.

Выведи:

~~~text
Allowed: True
~~~

или `Allowed: False`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `20 1` | `Allowed: True` |
| `17 1` | `Allowed: False` |
| `20 0` | `Allowed: False` |

bash run_tests3_5.sh
