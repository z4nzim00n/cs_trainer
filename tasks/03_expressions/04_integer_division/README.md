## CS_03_04. Целочисленное деление

### Задание
| CS_03_04 ||
| ------ | ------- |
| **Темы:** | `/`, `%`, отрицательные числа |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа `a` и `b` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи частное и остаток от деления `a` на `b`:

~~~text
7 / 2 = 3
7 % 2 = 1
~~~

`b` не равен нулю.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `7 2` | `7 / 2 = 3`<br>`7 % 2 = 1` |
| `-7 2` | `-7 / 2 = -3`<br>`-7 % 2 = -1` |

bash run_tests3_4.sh
