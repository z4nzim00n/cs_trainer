# Разбор задания

## Деление целых

~~~csharp
int quotient = a / b;
int remainder = a % b;
~~~

Если оба операнда `int`, дробная часть отбрасывается к нулю. Для `-7 / 2`
результат `-3`, а остаток `-1`.

## Связь частного и остатка

~~~text
a = b * (a / b) + (a % b)
~~~

Проверка: `-7 = 2 * (-3) + (-1)`.

## Деление на ноль

`a / 0` для целых бросает `DivideByZeroException`. В этой задаче `b ≠ 0`.

## Отличие от double

| Выражение | Результат |
| --- | --- |
| `7 / 2` | `3` |
| `7 / 2.0` | `3.5` |
| `7 % 2` | `1` |
