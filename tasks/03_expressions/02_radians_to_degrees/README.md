## CS_03_02. Радианы в градусы

### Задание
| CS_03_02 ||
| ------ | ------- |
| **Темы:** | `double`, `Math.PI`, преобразование величин |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Угол в радианах |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Переведи угол из радиан в градусы и выведи результат с двумя знаками:

~~~text
Degrees: 180.00
~~~

Формула: `градусы = радианы · 180 / π`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3.14159265358979` | `Degrees: 180.00` |
| `1.5707963267949` | `Degrees: 90.00` |
