## CS_09_01. Безопасное деление

### Задание
| CS_09_01 ||
| ------ | ------- |
| **Темы:** | `try`/`catch`, `DivideByZeroException` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа `a` и `b` |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Раздели `a` на `b`. Если `b` равно нулю, не падай, а выведи ошибку:

~~~text
Result: 5
~~~

~~~text
Error: division by zero
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `10 2` | `Result: 5` |
| `7 0` | `Error: division by zero` |

bash run_tests9_1.sh
