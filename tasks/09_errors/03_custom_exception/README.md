## CS_09_03. Своё исключение

### Задание
| CS_09_03 ||
| ------ | ------- |
| **Темы:** | `Exception`, конструктор, `throw`, `catch` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Возраст (целое число) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши исключение `NegativeAgeException`. Если возраст отрицательный,
брось его и выведи сообщение:

~~~text
Age: 20
~~~

~~~text
Error: age cannot be negative
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `20` | `Age: 20` |
| `-5` | `Error: age cannot be negative` |

bash run_tests9_3.sh
