## CS_09_05. Выход за границы

### Задание
| CS_09_05 ||
| ------ | ------- |
| **Темы:** | массив, `IndexOutOfRangeException`, `try`/`catch` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` чисел, затем индекс |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи элемент массива по индексу. Если индекс вне диапазона,
выведи ошибку:

~~~text
Value: 3
~~~

~~~text
Error: index out of range
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5`<br>`2` | `Value: 3` |
| `5`<br>`1 2 3 4 5`<br>`10` | `Error: index out of range` |
| `3`<br>`1 2 3`<br>`-1` | `Error: index out of range` |

bash run_tests9_5.sh
