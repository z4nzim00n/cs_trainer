## CS_09_02. Разбор числа

### Задание
| CS_09_02 ||
| ------ | ------- |
| **Темы:** | `int.TryParse`, `out`, ветвление |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Преобразуй строку в число. Если это невозможно, выведи `Invalid number`:

~~~text
Number: 42
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `42` | `Number: 42` |
| `abc` | `Invalid number` |
| `-7` | `Number: -7` |
