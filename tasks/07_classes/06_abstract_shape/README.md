## CS_07_06. Абстрактная фигура

### Задание
| CS_07_06 ||
| ------ | ------- |
| **Темы:** | `abstract`, `override`, `double`, `F2` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `circle R` или `rect W H` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши абстрактный класс `Shape` с методом `Area()` и наследников
`Circle` и `Rectangle`. Выведи площадь с двумя знаками:

~~~text
Area: 12.57
~~~

Для круга используй `Math.PI * R * R`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `circle 2` | `Area: 12.57` |
| `rect 3 4` | `Area: 12.00` |

bash run_tests7_6.sh
