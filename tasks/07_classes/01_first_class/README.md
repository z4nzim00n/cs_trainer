## CS_07_01. Первый класс

### Задание
| CS_07_01 ||
| ------ | ------- |
| **Темы:** | класс, поля, конструктор, `new` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа `x` и `y` |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши класс `Point` с полями `X` и `Y`, создай объект и выведи его:

~~~text
(3, 4)
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3 4` | `(3, 4)` |
| `-1 0` | `(-1, 0)` |
