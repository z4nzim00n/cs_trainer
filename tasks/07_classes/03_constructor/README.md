## CS_07_03. Конструктор и свойства

### Задание
| CS_07_03 ||
| ------ | ------- |
| **Темы:** | конструктор, свойства `get`, `readonly` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Имя и оценка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши класс `Student` с полями `Name` и `Grade`, создай объект и выведи:

~~~text
Student: Bob, Grade: 5
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `Bob 5` | `Student: Bob, Grade: 5` |
| `Alice 4` | `Student: Alice, Grade: 4` |
