## CS_07_05. Наследование

### Задание
| CS_07_05 ||
| ------ | ------- |
| **Темы:** | базовый класс, `virtual`, `override`, полиморфизм |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `dog` или `cat` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши базовый класс `Animal` с виртуальным методом `Speak()` и наследников
`Dog` и `Cat`. Выведи звук животного:

~~~text
Woof
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `dog` | `Woof` |
| `cat` | `Meow` |
