## CS_07_04. Переопределение ToString

### Задание
| CS_07_04 ||
| ------ | ------- |
| **Темы:** | `override`, `ToString`, интерполяция |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Два целых числа `x` и `y` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Переопредели `ToString()` у класса `Point` так, чтобы `Console.WriteLine(p)`
печатал:

~~~text
Point(1, 2)
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1 2` | `Point(1, 2)` |
| `-3 7` | `Point(-3, 7)` |
