## CS_11_05. Параллельная сумма

### Задание
| CS_11_05 ||
| ------ | ------- |
| **Темы:** | `Task`, `Task.WaitAll`, разбиение массива |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Раздели массив на две половины, сложи каждую в отдельной задаче и
выведи общий результат:

~~~text
Sum: 15
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `Sum: 15` |
| `4`<br>`-1 10 -2 3` | `Sum: 10` |

bash run_tests11_5.sh
