## CS_11_03. Счётчик с lock

### Задание
| CS_11_03 ||
| ------ | ------- |
| **Темы:** | `lock`, общий счётчик, гонка данных |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Количество потоков `n` и число инкрементов `m` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Запусти `n` потоков, каждый увеличивает общий счётчик `m` раз.
Выведи итог:

~~~text
Counter: 4000
~~~

Используй `lock`, чтобы не потерять обновления.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `4 1000` | `Counter: 4000` |
| `1 5` | `Counter: 5` |

```bash
bash run_tests11_3.sh
```
