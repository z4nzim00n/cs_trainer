## CS_08_05. Инверсия словаря

### Задание
| CS_08_05 ||
| ------ | ------- |
| **Темы:** | `SortedDictionary`, индексатор, пары |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` строк `ключ число` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поменяй местами ключи и значения и выведи по возрастанию числа:

~~~text
1: a
2: b
3: c
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3`<br>`a 1`<br>`b 2`<br>`c 3` | `1: a`<br>`2: b`<br>`3: c` |
| `2`<br>`x 10`<br>`y 5` | `5: y`<br>`10: x` |
