## CS_08_04. Группировка по длине

### Задание
| CS_08_04 ||
| ------ | ------- |
| **Темы:** | `SortedDictionary`, `List<string>`, группы |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка со словами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сгруппируй слова по длине. Группы идут по возрастанию длины, слова
внутри группы — по алфавиту:

~~~text
3: cat dog sun
8: elephant
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `dog elephant cat sun` | `3: cat dog sun`<br>`8: elephant` |
| `aa b ccc` | `1: b`<br>`2: aa`<br>`3: ccc` |

```bash
bash run_tests8_4.sh
```
