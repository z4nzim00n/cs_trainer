## CS_08_01. Частота слов

### Задание
| CS_08_01 ||
| ------ | ------- |
| **Темы:** | `Dictionary`, `TryGetValue`, сортировка ключей |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Одна строка со словами |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Посчитай, сколько раз встречается каждое слово, и выведи по алфавиту:

~~~text
apple: 2
banana: 1
~~~

Порядок строк должен быть отсортирован по слову.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `apple banana apple` | `apple: 2`<br>`banana: 1` |
| `b a b a b` | `a: 2`<br>`b: 3` |

bash run_tests8_1.sh
