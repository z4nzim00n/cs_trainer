## CS_08_02. Поиск в словаре

### Задание
| CS_08_02 ||
| ------ | ------- |
| **Темы:** | `Dictionary`, `TryGetValue`, `Not found` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` строк `ключ значение`, затем ключ для поиска |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Загрузи пары в словарь и найди значение по ключу:

~~~text
Found: 7
~~~

Если ключа нет, выведи `Not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `3`<br>`apple 5`<br>`banana 7`<br>`kiwi 3`<br>`banana` | `Found: 7` |
| `2`<br>`a 1`<br>`b 2`<br>`z` | `Not found` |

### Как проверить

```bash
bash run_tests8_2.sh
```
