## CS_08_03. Уникальные элементы

### Задание
| CS_08_03 ||
| ------ | ------- |
| **Темы:** | `HashSet`, `List.Sort`, `string.Join` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи количество уникальных чисел и сами числа по возрастанию:

~~~text
Unique: 3
1 2 3
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 1 3 2 1` | `Unique: 3`<br>`1 2 3` |
| `4`<br>`7 7 7 7` | `Unique: 1`<br>`7` |
