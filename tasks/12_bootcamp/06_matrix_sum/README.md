## CS_12_06. Сумма и диагональ

### Задание
| CS_12_06 ||
| ------ | ------- |
| **Темы:** | двумерный массив, вложенные циклы |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` строк по `n` чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи сумму всех элементов и сумму главной диагонали:

~~~text
Sum: 10
Diagonal: 5
~~~

Главная диагональ — элементы `a[i, i]`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2`<br>`1 2`<br>`3 4` | `Sum: 10`<br>`Diagonal: 5` |
| `1`<br>`7` | `Sum: 7`<br>`Diagonal: 7` |
