## CS_12_01. Простое число

### Задание
| CS_12_01 ||
| ------ | ------- |
| **Темы:** | цикл, `%`, `Math.Sqrt`, `bool` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Целое число `n` |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Определи, является ли число простым:

~~~text
True
~~~

Выведи `True` или `False`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `7` | `True` |
| `9` | `False` |
| `1` | `False` |
