## CS_12_05. Поворот матрицы

### Задание
| CS_12_05 ||
| ------ | ------- |
| **Темы:** | двумерный массив, индексы |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` строк по `n` чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поверни квадратную матрицу на 90° по часовой стрелке и выведи её:

~~~text
2
1 2
3 4
→ 3 1
  4 2
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `2`<br>`1 2`<br>`3 4` | `3 1`<br>`4 2` |
| `1`<br>`7` | `7` |

### Как проверить

```bash
bash run_tests12_5.sh
```
