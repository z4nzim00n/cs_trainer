# Разбор задания

## Куда переходит элемент

При повороте на 90° по часовой стрелке элемент `a[i, j]` встаёт в
позицию `b[j, n - 1 - i]`.

Обратная формула, удобная для заполнения результата:

~~~text
b[i, j] = a[n - 1 - j, i]
~~~

## Код

~~~csharp
int[,] b = new int[n, n];
for (int i = 0; i < n; ++i)
{
    for (int j = 0; j < n; ++j)
    {
        b[i, j] = a[n - 1 - j, i];
    }
}
~~~

## Вывод

~~~csharp
for (int i = 0; i < n; ++i)
{
    string[] row = new string[n];
    for (int j = 0; j < n; ++j)
    {
        row[j] = b[i, j].ToString();
    }
    Console.WriteLine(string.Join(" ", row));
}
~~~

## Трассировка 2×2

| Элемент | Позиция после поворота |
| --- | --- |
| `a[0,0] = 1` | `b[0,1]` |
| `a[0,1] = 2` | `b[1,1]` |
| `a[1,0] = 3` | `b[0,0]` |
| `a[1,1] = 4` | `b[1,0]` |

Результат: `3 1` / `4 2`.
