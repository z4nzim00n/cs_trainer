## CS_12_03. Статистика

### Задание
| CS_12_03 ||
| ------ | ------- |
| **Темы:** | минимум, максимум, сумма, среднее, `F2` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи минимум, максимум, сумму и среднее:

~~~text
Min: 1
Max: 5
Sum: 15
Average: 3.00
~~~

Среднее — с двумя знаками после точки.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `Min: 1`<br>`Max: 5`<br>`Sum: 15`<br>`Average: 3.00` |
| `3`<br>`2 4 9` | `Min: 2`<br>`Max: 9`<br>`Sum: 15`<br>`Average: 5.00` |

bash run_tests12_3.sh
