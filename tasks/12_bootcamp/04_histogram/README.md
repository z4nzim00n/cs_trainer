## CS_12_04. Гистограмма

### Задание
| CS_12_04 ||
| ------ | ------- |
| **Темы:** | `SortedDictionary`, `new string`, подсчёт |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` чисел от `0` до `9` |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Построй гистограмму: для каждого встретившегося значения выведи его и
столько звёздочек, сколько раз оно встретилось. Значения — по возрастанию:

~~~text
2: ***
5: **
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`2 5 2 2 5` | `2: ***`<br>`5: **` |
| `3`<br>`0 9 0` | `0: **`<br>`9: *` |

### Как проверить

```bash
bash run_tests12_4.sh
```
