## CS_05_06. Циклический сдвиг

### Задание
| CS_05_06 ||
| ------ | ------- |
| **Темы:** | `%`, индексы, новый массив |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, `k`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сдвинь список вправо на `k` позиций и выведи через пробел:

~~~text
5 2
1 2 3 4 5
→ 4 5 1 2 3
~~~

`k` может быть больше `n`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5 2`<br>`1 2 3 4 5` | `4 5 1 2 3` |
| `4 0`<br>`1 2 3 4` | `1 2 3 4` |
| `3 5`<br>`1 2 3` | `2 3 1` |

```bash
bash run_tests5_6.sh
```
