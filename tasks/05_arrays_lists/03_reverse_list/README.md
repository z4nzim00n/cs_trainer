## CS_05_03. Разворот списка

### Задание
| CS_05_03 ||
| ------ | ------- |
| **Темы:** | `List<int>`, `Reverse`, `string.Join` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи числа в обратном порядке через пробел:

~~~text
5
1 2 3 4 5
→ 5 4 3 2 1
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `5 4 3 2 1` |
| `3`<br>`10 20 30` | `30 20 10` |
