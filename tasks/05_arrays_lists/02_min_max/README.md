## CS_05_02. Минимум и максимум

### Задание
| CS_05_02 ||
| ------ | ------- |
| **Темы:** | `List<int>`, `int.MinValue`, `int.MaxValue` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди минимальное и максимальное значения:

~~~text
Min: 1
Max: 9
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`4 9 1 7 3` | `Min: 1`<br>`Max: 9` |
| `3`<br>`-5 -2 -8` | `Min: -8`<br>`Max: -2` |
