## CS_05_01. Сумма и среднее

### Задание
| CS_05_01 ||
| ------ | ------- |
| **Темы:** | `List<int>`, `for`, среднее, `F2` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Найди сумму и среднее арифметическое списка:

~~~text
Sum: 15
Average: 3.00
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`1 2 3 4 5` | `Sum: 15`<br>`Average: 3.00` |
| `3`<br>`2 4 9` | `Sum: 15`<br>`Average: 5.00` |
