## CS_05_05. Сортировка

### Задание
| CS_05_05 ||
| ------ | ------- |
| **Темы:** | `List.Sort`, `string.Join` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Отсортируй числа по возрастанию и выведи через пробел:

~~~text
5
3 1 4 2 5
→ 1 2 3 4 5
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `5`<br>`3 1 4 2 5` | `1 2 3 4 5` |
| `4`<br>`10 -1 3 0` | `-1 0 3 10` |

bash run_tests5_5.sh
