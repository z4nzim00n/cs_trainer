## CS_05_04. Убрать дубликаты

### Задание
| CS_05_04 ||
| ------ | ------- |
| **Темы:** | `HashSet<int>`, `List<int>`, порядок элементов |
| **Файл решения:** | Program.cs |
| **Входные данные:** | `n`, затем `n` целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Оставь только первое вхождение каждого числа, сохранив исходный порядок:

~~~text
7
1 2 1 3 2 4 1
→ 1 2 3 4
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `7`<br>`1 2 1 3 2 4 1` | `1 2 3 4` |
| `4`<br>`5 5 5 5` | `5` |

```bash
bash run_tests5_4.sh
```
