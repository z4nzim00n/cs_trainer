## CS_10_01. Чтение файла

### Задание
| CS_10_01 ||
| ------ | ------- |
| **Темы:** | `File.ReadAllText`, `FileNotFoundException` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Прочитай файл и выведи его содержимое без изменений:

~~~text
hello
world
~~~

Если файла нет, выведи `Error: file not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `input.txt` (содержит `hello`) | `hello` |
| `missing.txt` | `Error: file not found` |

### Как проверить

```bash
bash run_tests10_1.sh
```
