## CS_10_03. Копирование файла

### Задание
| CS_10_03 ||
| ------ | ------- |
| **Темы:** | `File.Copy`, перезапись, `check_file` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Исходный файл и файл назначения |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Скопируй файл и подтверди:

~~~text
Copied: copy.txt
~~~

Если файл назначения существует, он заменяется.
