## CS_10_04. Сумма чисел из файла

### Задание
| CS_10_04 ||
| ------ | ------- |
| **Темы:** | `ReadAllText`, `Split`, `long` |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Имя файла с числами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Прочитай числа из файла и выведи их сумму:

~~~text
Sum: 15
~~~

Числа разделены пробелами и переводами строк.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `numbers.txt` (`1 2 3` / `4 5`) | `Sum: 15` |

### Как проверить

```bash
bash run_tests10_4.sh
```
