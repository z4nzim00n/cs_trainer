## CS_10_06. Статистика файла

### Задание
| CS_10_06 ||
| ------ | ------- |
| **Темы:** | `File.ReadAllLines`, строки, символы |
| **Файл решения:** | Program.cs |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи статистику файла:

~~~text
Lines: 2
Words: 3
Chars: 13
~~~

- `Lines` — количество строк;
- `Words` — количество слов;
- `Chars` — количество символов без пробельных.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `text.txt` (`hello world` / `foo`) | `Lines: 2`<br>`Words: 3`<br>`Chars: 13` |
